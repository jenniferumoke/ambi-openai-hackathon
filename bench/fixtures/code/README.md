# Two Sum repair exercise

This is a fictional coding workspace for AMBI-Bench. `exercise.py` is intentionally wrong.

Repair `two_sum(nums, target)` so it returns two distinct indices, or `None` if
there is no solution. Do not mutate the input. Handle duplicates and negatives.

Examples:

- `[2, 7, 11, 15]`, target `9` → `[0, 1]`
- `[3, 3]`, target `6` → `[0, 1]`
- `[-3, 4, 3, 90]`, target `0` → `[0, 2]`
- `[1, 2, 3]`, target `99` → `None`

Use one plain Python function without imports, decorators, recursion or file I/O.
The benchmark executes this limited exercise against its own test vectors.
Passing these examples does not establish general coding-agent quality.
