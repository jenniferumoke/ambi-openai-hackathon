How the profile lab works

A prepared person, a realistic work context, and a short review of AMBI’s behavior.

1. Load a profileIdentity, preferences, two weeks of memory, and fresh source files.
↓
2. Open the scenarioAn invoice, an unanswered email, a trip plan, or an editor with failing tests.
↓
3. Observe the actual AMBI appLet the greeting finish. Show the source without asking for the expected answer.
↓
4. Save a simple reviewHelpful, unwanted, correctly quiet, missed, or not tested. Include what happened.

Clear boundaries

Each profile gets its own local memory database. Source documents and messages are fictional. Captures exclude the greeting and raw user transcript; a user turn is flagged so a prompted response is not mistaken for proactivity. Camera cues are optional hints, not mood labels.

The VNC environment is still being prepared. For now, use this machine. The same profile manifests and source packs can be loaded on the test machine once AMBI works there.
