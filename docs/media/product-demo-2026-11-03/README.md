# Recorded Ambi product demo

[Watch the 95-second video](ambi-product-demo.mp4) · [Captions](captions.srt)

Edited recordings of real native Mac and Windows candidate tests, with clearly labelled OpenAI-generated editorial narration and original app speech. Typed instructions were used with the microphone muted. The video includes real Calculator/Notepad work, active frame/Stop controls, Windows editing recovery and browser-handoff UI preview. Speed changes and separate tests are labelled. The earlier test file’s saved contents were independently unchanged; the new requested text matched exactly.

Browser material is a synthetic interface preview, not authenticated chat automation. Linux is a source preview, not an installed/tested Linux build. These narrow examples do not establish general reliability, production readiness or full distribution acceptance. See [dated platform evidence](../../verification-2026-11-03.md).

Original footage and private test evidence remain outside the repository. No keys, launch dialogs, recordings of microphone input or Codex credentials are included. The soundtrack uses OpenAI speech generated through Ambi’s own configured idle voice connection without retrieving its key; only playback audio was captured. All narration responses matched their scripts. The preceding system-voice export was retained locally and is not used here.

`verification.json` records the checksum, H.264/AAC format, full decode and audio-level checks. Captions are burned in with the separate SRT retained for editing. `narration.txt` contains the six editorial passages. Narration is AI-generated and does not imply a human speaker.
